# 标题字体来源

- 字体：Adobe Source Han Serif / 思源宋体，简体中文可变 WOFF2，原文件未修改、未子集化。
- 官方项目：https://github.com/adobe-fonts/source-han-serif
- 下载：https://raw.githubusercontent.com/adobe-fonts/source-han-serif/release/Variable/WOFF2/OTF/SourceHanSerifSC-VF.otf.woff2
- 许可：SIL Open Font License 1.1；原许可随源代码及发行程序一起保留。
- `Zhaoye Heading` 仅为 CSS 字体别名，不修改字体内部名称。不声称是效果图的真实字体，仅选择相近的宋体标题字形。
- 本字体仅用于 Markdown 标题，系统 UI 仍为等宽字体，正文及 EPUB 书籍字体设置不变。
