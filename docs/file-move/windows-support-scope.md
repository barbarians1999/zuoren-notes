# Windows 资料文件移动支持范围

0.4.2 起，Windows x64 可在固定本地 NTFS 或 exFAT 卷的已授权资料根目录内移动文件。文件可拖入子目录，也可拖到返回按钮或地址栏中的父目录；移动前保存未保存内容，完成后同步路径、阅读记录和撤销信息。目标同名时拒绝移动，不覆盖文件。

卷根目录、可移动卷、网络卷、重解析路径、未授权根目录以及原生 worker 或文件身份核验失败的情况都会拒绝操作。撤销前会重新核对文件身份和摘要。

每个正式版本的 `VALIDATION.json` 记录实际运行的测试和跳过项。Windows 若拒绝创建符号链接测试夹具并返回 `EPERM`，对应测试只能记为跳过，不能视为通过；该环境下的符号链接专项行为仍未验证。
