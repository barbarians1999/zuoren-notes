## 本次交付范围

编辑器以 Markdown 字符串为唯一文档正文；CodeMirror transaction 修改正文，Live Preview 只改变显示，不把渲染后的 HTML 反写文件。移除未使用的 Milkdown/ProseMirror 编辑分支、依赖和旧剪贴板转换器。改造前源码备份位于 `work/architecture-before-20260922-101750`。

### 模块边界

- `src/editor/MarkdownSourceEditor.tsx`：编辑器生命周期、本地输入与外部快照区分。外部重新加载清空旧撤销历史，字体变化不重建编辑器。
- `markdownLanguage.ts` / `markdownLivePreview.ts`：语法树和显示装饰。代码块、转义文本不会误变成任务框或删除线；多行选区保留源码。
- `markdownRendering.ts` / `MarkdownPreview.tsx`：阅读渲染及清洗、本地图片解析。图片只从真正的图像节点解析，代码示例中的图片语法保持原样。
- `markdownCommands.ts` / `markdownClipboard.ts`：格式命令、源文本复制、网页富文本粘贴。复制同时提供普通文本和 Markdown；合法反斜杠、源码中的 `<br />` 不再被无差别删除。
- `src/documentPersistence.cjs`：左右栏共用保存和磁盘检查协调器。UI 提供文档快照，不从编辑器 DOM 推导磁盘正文。
- `src/readers`：独立 PDF、EPUB 组件；`src/workspace`：副栏和冲突对话框；`src/main.tsx` 保留窗口工作区协调。
- `electron/note-service.cjs`：正文保存与恢复稿清理分离。正文成功后，清理失败不再谎报正文未保存。

### 保存与关闭

输入 → 本地修订号 → 延迟保存 → 同步占用保存队列 → 恢复稿 → IPC 写盘 → hash/正文确认。

保存期间继续输入会排队保存最新版本。磁盘检查返回后核对文档对象、文本、修订号及保存代次，过期结果丢弃。主栏“保留我的内容”也进入同一保存队列。关闭前等待两栏正文、PDF/EPUB 标注和阅读进度、会话写入；失败时不确认关闭。

后端继续使用既有目录授权、原子写入、条件恢复稿清理；IPC 验证主窗口主 frame。外链导航交给系统浏览器。PDF/EPUB 身份校验缓存基于文件状态指纹，文件变化后重新计算，拒绝用旧身份写入标注。

## 表格使用

```markdown
| 项目 | 说明 | 数量 |
| :--- | :---: | ---: |
| **粗体** | ==高亮== | 2 |
| 普通内容 | ~~删除线~~ | 3 |
```

支持表头、左/中/右对齐、单元格行内格式。光标在表格外时显示排版表格，点击单元格进入对应 Markdown 源码位置；离开后恢复排版。支持撤销。选中文本工具条及命令面板都有“插入表格”。这是连续源码编辑，不是单元格富文本编辑器；合并单元格不属于 GFM 表格语法。

## 边界与后续工作

本轮不宣称消灭所有竞态或所有 Markdown 差异。源码语法树与阅读渲染分别采用 Lezer 和 Marked，已覆盖的语法有回归测试，复杂 HTML、脚注及第三方扩展不保证一致。超长文档装饰更新和 PDF/EPUB 按需加载仍可继续优化；当前主脚本仍有体积警告。

完整 UI 冒烟默认不执行 OCR 识别；需要本地 OCR 模型时使用 `ZHAOYE_SMOKE_OCR=1` 额外验证。安装包构建和其中的可执行程序检查不等于已替用户完成安装。本轮不终止正在运行的旧安装版，也不修改用户笔记。
