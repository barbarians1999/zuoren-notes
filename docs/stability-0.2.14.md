# 0.2.14 稳定性边界与回归记录

## 改造依据

参考 horseMD 的 [更新记录](https://github.com/BND-1/horseMD/blob/main/CHANGELOG.md) 与
[source/rich divergence incident](https://github.com/BND-1/horseMD/blob/main/docs/rich-source-divergence-incident-0.13.47.md)。
借鉴的是竞态、输入法、长会话、虚拟 DOM 复制及诊断开销的教训，不照搬其富文本双模型。

## 当前契约

- CodeMirror 文档是 Markdown 编辑的唯一正文来源。复制读取模型，不读取可见 `.cm-line`；渲染不回写正文。
- 主副栏统一使用 `workspace/useNoteSession.ts`。同一门禁控制保存、恢复定时器与磁盘轮询：启动完成、没有恢复/外部冲突、路径没有被重命名/删除屏障阻断。
- `documentPersistence.cjs` 串行写入；慢写期间的新输入继续保存，直到当前版本落盘才完成 flush。
- 保存确认只更新磁盘基线，不替换编辑器文档、不清空撤销。主动重载/恢复版本选择才重置文档历史。
- 搜索和目录请求使用 `asyncRequest.cjs` 代数门禁；新查询、清空查询或更换根目录使旧结果失效。
- 摘录绑定来源书籍、目标笔记生命周期、原编辑器注册函数；异步定位期间切换文件后拒绝插入。
- PDF/EPUB 共用 `metadataWriter.cjs`。每次功能性修改合并到最近成功提交的版本，失败不推进基线。
- EPUB 的进度、字号与标注分别提交增量意图；关闭 flush 不携带旧的整份标注快照。
- 自定义剪切与粘贴使用独立撤销分组，避免和紧接着的输入合并。
- 查找/替换使用统一布局阶段焦点规则，移除互相竞争的延迟 focus，避免刚打开查找时输入跑进替换框。
- 关闭标签页选择放弃未保存修改后，关闭流程不再把该编辑稿重新提交。
- 主副栏冲突都必须明确选择版本，移除会绕过恢复门禁的关闭入口。

## Live Preview

保留连续源码编辑、活动行语法显露及标题、强调、高亮、删除线、任务、列表、嵌套引用、分隔线、表格、代码块。
真实 Tab 仍按 4 列显示。`markdownPolicy.ts` 统一非标准 `==高亮==` 的转义、单行与行内代码边界。
阅读端仍使用 Marked，编辑端仍使用 Lezer；没有宣称两个解析器完全等价。
`tests/fixtures/markdown-contract.cjs` 是两侧共用的行为语料。

光标在相同活动行内移动复用装饰；选区跨行时不强制全篇同步解析。输入解析预算降为 20 ms，后台语法树更新继续补齐。
跨行与文档变更仍会遍历已有语法树；大型结构密集文档进一步做局部/视口缓存是后续优化，不假称已完成。

## 诊断

`window.readerDiagnostics.snapshot()` 只保留最近 200 条保存/恢复/轮询元数据事件，记录栏位、生命周期 ID、编辑与提交版本。
不记录正文、剪贴板、全路径；默认仅驻内存，不持续写磁盘。此接口用于定位首个分歧，不用于证明所有场景无 bug。

## 发布门禁

1. 构建/类型检查及全部单测。
2. 编辑器与共同语料：真实 CDP IME composition + 紧接 Enter、连续剪贴/预览/撤销、多轮操作、成功保存的模型与磁盘对比、切文件及冷重启。
3. 人为延迟搜索/目录响应，确认旧请求确实完成但不覆盖新选择。
4. 主副栏恢复冲突/可恢复稿、保存失败、路径复用、启动及关闭保护。
5. 阅读器缩放、导航、失败后重试与摘录撤销。
6. 独立 0.2.14 安装包及同批 `win-unpacked` 可执行文件回归。不覆盖正在运行的已安装版本，不删除历史发布。

## 留待后续

- 大文档装饰局部缓存与结构密集性能基准。
- 更广的 CommonMark/GFM 差分语料，而非临时整篇规范化来掩盖差异。
- EPUB 主阅读 iframe 与标注侧栏的完整故障注入回归；目前元数据队列有确定性单测，阅读器实测覆盖导航/字号/关闭保存。
- 代码拆包（当前构建仍有较大 chunk 警告），与稳定性改造分开验证。

Git 已保存 0.2.13 改造前基线；每个新复现用例与实现变更一起版本化。

## 本轮问题账本

| 问题 | 定位与处置 | 防复发用例 |
| --- | --- | --- |
| 副栏恢复冲突期间仍可能被轮询更新 | 原副栏 poll 门禁缺恢复状态；迁移统一 session 门禁 | startup-preservation-smoke 的 secondary conflict，等待跨过轮询周期后检查恢复稿与编辑器 |
| 粘贴后的输入撤销连带删掉粘贴文本 | 连续 IME/剪贴场景首次复现；自定义 paste/cut 增加 isolateHistory | stability-smoke 连续四轮模型逐字对比 |
| Ctrl+H 后查询偶尔无法找到结果 | 首次全量测试失败，单独重跑通过；检查发现 find 与 replace 两个延迟 focus 竞争，改布局阶段统一聚焦 | stability-smoke 快速打开并输入六轮；electron-smoke 双栏完整查找/替换 |
| 放弃编辑稿后关闭流程再次提交 | 原关闭标签页 proceed 无条件保存；先恢复已确认磁盘基线再继续关闭 | stability-smoke discard-canary，逐字核对磁盘内容 |

没有用增加固定等待时间把这些失败遮住；连续输入用例只在真正的保存确认、IPC 完成或冷启动边界等待。
