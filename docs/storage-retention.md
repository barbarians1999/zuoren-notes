本台账区分可再生的测试/构建数据与源码、恢复资料。下列容量来自 2026-10-21 的磁盘任务交接，是历史观察值，不代表本次重新扫描。

| 路径或类别 | 用途 | 观察到的容量／状态 | 处理规则 |
| --- | --- | --- | --- |
| work/legacy-workspace/ | 完整旧 Git 工作区与救援副本 | 约 3.61 GiB；其中 original-workspace/.git 约 3.55 GiB | 原位完整保留；不合并、不 prune、不当作缓存；不再生成整套重复工作区快照。 |
| releases/<版本>/ | 已验收的 Windows 交付 | 只有通过回执确认的当前版本保留 | 保留当前安装包和验证证据；旧版本只经 pnpm release --cleanup 回收。 |
| D:\C盘分担\保留备份\ | 用户指定的离线档案 | 提供的迁移日志仍列为迁移中；指定完成回执当时未找到 | 不改动，也不用于测试临时数据；D 盘至少保留 8 GiB。 |
| D:\C盘分担\过期产物隔离\2026-10-21\ | 用户指定的已核验隔离副本 | 最新交接称 4 项无关旧产物已校验迁移 | 不把它们当作左人笔记项目产物再次处理。 |
| D:\C盘分担\左人笔记临时\zuoren-* | 每次原生 UI 测试生成的工作区 | 单个工作区最多 512 MiB；受管目录最多 1 GiB | Windows 默认只有 D 盘有至少 9 GiB 空闲才启动原生 UI 测试；否则停止并提示。用户显式指定其他临时根后，仍须至少有 1 GiB 空闲。统一入口确认测试子进程退出后清理成功工作区；失败时只留测试资料和设置，删除浏览器缓存及临时截图，失败复现最多 256 MiB。 |
| outputs/ui-<版本>/integrity/installer-content-* | 安装包校验时临时解出的 app.asar | 仅用于和已测试程序比较 | 成功或失败都会在 finally 中清理；保留 installer-integrity.json 和发布日志。 |
