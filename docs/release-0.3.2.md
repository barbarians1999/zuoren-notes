# 0.3.2 PDF 夜间阅读

日期：2026-10-09。

## 改动

- PDF 跟随软件已解析的主题（包括“跟随系统”）：深色时文字页黑底浅字；图片及整页扫描保持原色，亮度降至 65%。浅色时恢复原始页面。
- 页面显示与原始渲染分离。主题只重绘显示画布，不重新加载 PDF／文字层，不变更页码、缩放、标注格式或保存协议。
- PDF.js 图片位置记录用于保护图片颜色；补足其优化后的重复／内联图片组，保留旋转及归一化位置。
- 高亮／搜索在夜间使用 screen 叠色，不被黑纸面吞掉；文字选择仍为淡蓝色。
- 图片摘录仍由原始 PDF 单独渲染，输出原色；原文件不变。扫描页作为图片仅压暗，不进行 OCR 或扫描文字反色。
- 额外原色画布仅存在于已挂载的虚拟页面，随页面卸载释放；不对全部页进行预渲染或像素循环。
