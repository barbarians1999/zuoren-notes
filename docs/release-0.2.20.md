# 0.2.20：单行笔记顶栏

## 设计审查与范围

这是保留式调整：原主题的 surface/accent/line、系统界面字体、笔记正文仿宋和图标系列不变。设计参数为 DESIGN_VARIANCE=3、MOTION_INTENSITY=1、VISUAL_DENSITY=5，采用项目现有 React/CSS/Lucide，不新增 UI 库或动画库。design-taste-frontend 面向营销网站，编辑器本身不在其范围；这里只借用审查、品牌保留和视觉检查原则，不应用 hero、图片、营销文案或网站字体替换要求。

旧界面有重复文件名、路径和两栏各自两行的工具区域。新布局仅保留一行，标签可横向滚动，右端操作区固定；正常状态不额外占行，错误仍保留文字。查找只在显式打开后出现临时查找条。

## 行为与边界

- 两组标签在同一连续顶栏内排列，仍属于各自文档视图；当前操作标签高亮，另一栏的当前标签以轻下划线指示。双栏使用左右提示，悬停查看完整路径。
- 正文、标签与顶部操作保持明确目标。编辑/阅读、保存、查找作用于当前操作视图，大纲、交换、合并和旧恢复稿入口在更多菜单。
- 标签保留排序与跨组拖动，可拖到另一栏正文；同文件合并、临时固定、共同撤销、恢复和保存不修改算法。
- 使用 React portal 将标签/操作移到共享顶栏，编辑器、滚动、查找和大纲仍由原视图持有，不重挂载正文组件。只将查找与保存的键盘目标扩展到顶栏。
- ResizeObserver 只在当前组的标签带尺寸变化时调整可见范围，不参与 React 连续状态更新。更多菜单支持 Esc、方向键与 Home/End。
- 不改会话格式、不迁移恢复稿、不触碰真实用户笔记。安装包制作不等于执行升级安装。

## 验证

旧测试仅调整顶栏入口与选择器，保留保存、冲突、失败和恢复的数据安全断言。增加单行布局、当前视图路由、顶部快捷键、窄窗口活动标签可见性、更多菜单与主题回归。最终计数和安装包一致性记录在发布目录的 VALIDATION.json 中。

视觉验收：单栏/双栏/对照、宽/窄窗口、亮/暗主题；无重复路径行、无换行标签、无持续装饰动画。营销网站专用检查项与 Lighthouse 不适用本地 Electron 工作区，不能声称通过网站性能指标。
