# 0.2.19：独立标签组与共享文档

## 操作

- 左右分别切换标签；单击侧栏打开临时标签，双击固定。输入、格式操作、阅读待办或摘录自动固定，常驻笔记不会被下次单击覆盖。
- Markdown 文件右键“在右侧打开”。笔记模式保留左栏，读书对照保留阅读器，只在已有笔记区域打开，不增加第三栏。
- 同文件可左侧编辑、右侧阅读，即时同步；同组不重复打开。标签右键显示菜单；“＋”创建空白标签，提供打开/新建入口。
- 标签支持组内排序、跨组拖动、同文件合并、整组交换和分屏合并。关闭优先选右邻，然后左邻；左组全关而右组仍有标签时，将右组提升到左侧。
- Ctrl+Tab / Ctrl+Shift+Tab 切换当前组，Ctrl+W 关闭当前标签。切换保留模式、位置和运行期间的撤销历史；重启不承诺恢复撤销历史。

## 架构与数据安全

- `noteWorkspace.ts` 管理两组视图、路径注册表和每组异步请求代次，一个计时器调度后台保存/恢复/轮询。
- `noteDocument.ts` 持有正文、共享 CodeMirror history、磁盘版本、保存/冲突状态与恢复编号。继续使用原 `DocumentPersistence`，不改原原子写盘/版本比较算法。
- `MarkdownSourceEditor.tsx` 的视图不再单独持有 history；本地 transaction 提交共享文档，广播不再加入 history，也不触发第二次保存。每栏只有当前标签挂载编辑器 DOM。
- `NoteViewState` 保存每个视图独立的模式、完整运行期选区与编辑/预览滚动；切换复用每栏编辑器，不读盘重建文档。隐藏笔记组不关闭，滚动记忆不被隐藏状态覆盖。
- 最后一个视图关闭前通过原队列保存；失败保留标签与草稿，用户可重试、取消或明确放弃。退出要求全部正文、阅读器元数据和现场保存成功。
- `ReaderSessionV3` 只保存路径、顺序、临时状态、模式、位置和恢复编号，不保存正文。兼容 V1/V2；旧版同路径的第二份恢复稿保留编号和原文件，可另存副本查看，不静默合并。无法读取恢复稿时不挂载自动保存编辑器。
- native 启动按完整 session 恢复文件授权，不局限于最多 30 项的最近文件列表。真实路径注册统一 Windows 身份；保存确认不重建编辑状态。
- 查找/保存/格式绑定本栏，摘录额外校验视图、文档与阅读器身份；旧请求不覆盖后来的选中标签，左右请求不互相取消。

## 验证和边界

新回归覆盖临时替换、固定保护、独立选择、共享 undo/redo、单保存者、保存期间输入、故障关闭、双视图崩溃恢复、拖动/交换/合并、快捷键、空白入口和 V3 恢复。旧 smoke 按新交互更新选择器和标签数量，保留数据安全断言；“放弃关闭”通过注入真实保存失败验证。

Live Preview、列表续写、Tab/空格缩进、表格、剪贴板、字体主题、PDF/EPUB 搜索和摘录继续使用原实现并运行完整回归。测试只使用隔离的临时笔记和 profile。

最终测试计数、安装包一致性及 SHA-256 记录在发布目录 `VALIDATION.json`、`SHA256SUMS.txt` 和任务输出报告中。安装包制作不等于执行 Windows 升级安装；不停止、不覆盖现有安装版。保留 0.2.18 安装包用于回退；回退前在 0.2.19 保存所有文档。旧恢复文件格式和用户笔记路径不迁移。
