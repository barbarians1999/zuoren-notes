# 0.2.18：EPUB 全书搜索与阅读模式待办

## 新功能

- EPUB 工具栏增加搜索入口，也可在正文 iframe 或阅读器内按 Ctrl+F。搜索面板按章显示匹配上下文，点击结果定位原文；Enter / Shift+Enter 切换结果，Esc 关闭。
- 支持中文、英文、区分大小写及跨行内格式节点的字面量搜索；不同段落不拼接成虚假词语。最多显示 500 项，超过时明确提示缩小关键词。
- 搜索独立加载 EPUB，不使用或卸载当前阅读器的章节对象；按章串行处理后释放。改词、关闭或换书取消旧任务及迟到结果；无法读取的章节单独计数。
- 原文定位使用临时下划线，独立于用户保存的高亮；关闭或改词移除临时标记，不写入标注数据。
- Markdown 阅读模式的 GFM 待办可直接勾选或取消；支持鼠标、键盘 Space，以及 Ctrl+Z、Ctrl+Y / Ctrl+Shift+Z 撤销、重做。

## 保存与编辑保护

- 阅读待办只修改对应 `[ ]` / `[x]` 的一个字符，通过现有 CodeMirror transaction 更新正文，再使用既有保存、恢复、冲突与失败重试链路。不增加另一个写盘入口。
- 任务位置来自 Markdown 语法树，并与本次渲染的随机身份和完整源码快照绑定。代码块、转义符号、原始 HTML 输入框及过期预览不具备写入权限。
- 磁盘正文含 CRLF 时转换至编辑器的 LF 偏移后再定位；存盘保留既有 BOM 与换行约定。主副栏沿用各自文档与撤销历史。
- 同一笔记预览仍保留旧画面直至新结果完成，保留滚动；旧画面的 checkbox 不能向新正文提交旧偏移。图片解析超时仍有原有降级，不会一直显示排版中。

## 测试与交付边界

- 新增 `markdown-tasks.test.cjs`、`epub-search.test.cjs`、`reading-actions-smoke.cjs`、`epub-search-smoke.cjs`，接入源码及包内测试入口。
- 待办覆盖嵌套、引用、CRLF/BOM、保存失败重试、撤销重做、跨文档隔离、外部冲突、延迟图片导致的过期预览与键盘操作。
- 搜索覆盖大小写、跨节点中英文、正确章节定位、结果上限、快速改词、iframe 快捷键、换书隔离、窄窗口布局和既有高亮保留。单元测试覆盖取消和损坏章节处理。
- 旧阅读器撤销回归由固定 1.3 秒等待改为等待编辑器与磁盘分别达到目标状态，避免把忙碌机器上的保存延迟误判为撤销丢失。
- 恢复回归由固定 1.4 秒等待改为检查磁盘正文与保存确认；长文统计回归在磁盘内容更新后等待保存队列确认，再请求切换文档。保留全部原断言，不放宽保存或恢复标准。
- 最终验证：96 项单元测试通过；同一套 17 个 smoke 文件在源码和包内程序中分别为 39 项通过、0 项失败。计数包含父测试与子测试。
- 已查看源码和包内的搜索宽/窄窗口与阅读待办截图。安装包内 `app.asar` 与受测包内程序逐字节一致；当前构建与 Electron 入口等 28 个文件也与包内内容一致。
- 安装包 SHA-256 与详细结果见发布目录 `VALIDATION.json` 和 `SHA256SUMS.txt`。前两轮失败与测试修正缘由保留；最终报告分别为 `outputs/reading-actions-0.2.18/source-smoke-verified.xml` 和 `packaged-smoke-verified.xml`，不覆盖前两轮记录。

本轮不重做整体界面，不迁移旧用户目录或设置键，不改变 GPU 模式，也不混入图片实时预览、公式、PDF 导出或保存架构重写。保留已有主题、字体、Live Preview、列表续写、缩进、PDF/EPUB 阅读与摘录功能。

测试使用独立临时文件和用户数据目录，不使用用户真实笔记。生成安装包不等于执行 Windows 升级安装；未关闭或替换用户现有安装版，也未删除旧安装包。
